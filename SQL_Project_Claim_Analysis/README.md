# 📊 Claims SQL Analysis Project
## 📌 Overview

This project analyzes claims data to identify financial risk, recovery performance, and patterns across carriers.

The goal is to simulate real-world business analysis using SQL and provide insights into:

- Risk exposure
- Recovery efficiency
- Carrier performance
## 📂 Dataset
Claims dataset including:
claim amount
approved amount
at-risk amount
claim status
carrier information
## 🔍 Key Analyses
1. Basic Data Exploration
Understand structure and key fields
2. Carrier Performance Analysis
Total claims and recovery amount by carrier
3. Claim Type Analysis
Identify which claim types drive higher losses
4. Aging Risk Analysis
Analyze overdue and time-barred claims
5. Financial Risk Segmentation (JOIN)
Identify which carrier segments drive the highest financial risk
## 🧠 Key Insight Example
Certain carrier segments contribute disproportionately to total at-risk exposure
Overdue claims significantly increase financial risk compared to other categories
